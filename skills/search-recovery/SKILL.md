# Search Recovery

1. Review the last failed query, outcome, and unresolved clue.
2. Determine whether the query was too narrow, too broad, or used the wrong alias.
3. Change one meaningful constraint at a time: remove extra words, substitute synonyms, or search an intermediate entity.
4. Prefer the corpus language; switch languages only when evidence suggests it.
5. Search again, compare with previous results, and inspect new candidates.
6. Do not repeat an identical failed query; stop when evidence is sufficient or budget is exhausted.

Never invent missing evidence, documents, or entities.
